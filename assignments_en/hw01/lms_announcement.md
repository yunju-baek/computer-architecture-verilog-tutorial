# Assignment 1: Function calls and architectural state

Implement an RV32I array sum and explain how calls change the PC, registers, and stack. Use `assignments_en/hw01/` in the student package. Submit through the corresponding LMS assignment entry by the deadline shown there.

## Required work

1. Complete `add_word` and `sum_array` in `programs/state_contract.s`. Preserve the values needed across nested calls and restore `ra`, `sp`, and any used `s0`–`s2` registers before returning. Use the provided C code as a reference.
2. Select one trace row each for `call`, an array load `lw`, a stack store `sw`, and `ret`. Choose the call to `add_word` inside `sum_array` and the return from `sum_array` to `main`. Explain the current PC, changed state, and next PC for all four events.
3. Complete the empty-array `[]` and wraparound `[0xffffffff, 1]` tests in `tests/test_student_cases.py`. Write your predictions first. Both tests must assert `a0` and `sp`.
4. Predict the effect of omitting the `ra` restore in report section 4, then run the experiment. Compare the separate source generated by the tool with normal execution. Keep your normal submission source intact.

## Run

Use Python 3.11 or later and GNU Make. Run these commands in `assignments_en/hw01/`.

```bash
make setup-check
make test
make evidence
# Write the prediction in report section 4 before running this command.
make ra-experiment
```

If your code has multiple restore instructions, follow the README procedure for `RESTORE_LINE`. The `make test-c` check, additional C implementation, and machine-code field analysis are optional study activities.

## Submission and grading

Submit your completed `hw01` folder with:

- `programs/state_contract.s` and `tests/test_student_cases.py`
- All four sections of `report.md` and your verification record in `integrity.txt`

Keep the supplied C reference, tools, and public tests in the folder. The assignment is worth 100 points: implementation 50, verification 30, report 20. Record the resources and tools you used, and verify your submitted results yourself.
