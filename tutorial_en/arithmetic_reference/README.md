# Optional arithmetic reference

Use the completed Python examples to inspect signed values, carry and overflow, multiplication and division traces, and accumulator width. This material supports classroom questions and optional study.

```bash
make test
make demo
```

Before running the code, predict the result, carry, and overflow for `0x7fffffff + 1` and `0xffffffff + 1`. Compare your predictions with the output. You can also compare the wide and narrow `dot_i16` accumulators. These activities have no separate assignment submission. Required RTL work is [HW02](../../assignments_en/hw02/README.md).
